# Asset specifications

PTF Studio 1.0 documents wallpaper 480 × 272 BMP; preview image 300 × 170 GIM RGBA; preview icon 16 × 16 indexed GIM; category icon 64 × 48 indexed GIM; first-level body 48 × 48 and focus 64 × 64 indexed GIM; second-level body 32 × 32 and focus 48 × 48 indexed GIM. The built PTF uses these sizes and zlib compression. See Validation_Report.md for the actual checks and limitations.

Slots are named by group and sub-index in `Source/Theme_Project`; the group 3 slot meanings follow the PTF Studio mapping. The original high-resolution masters are flattened bitmap artwork; generated PNG inputs can be edited individually. The 480 × 272 BMP provided separately is 24-bit RGB.
