# Installation

The PTF has passed structural and image decoding checks but has not been tested on hardware.

1. Connect the PSP to your computer with its USB cable. Open Settings → USB Connection on the console.
2. On PSP Go, select and open internal system storage for `ef0:`. If you choose a Memory Stick instead, use its `ms0:` storage. On a standard PSP, open the Memory Stick `ms0:`.
3. Locate or create `PSP/THEME` at the root of the selected storage.
4. Copy `Rayman_Raving_Rabbids_Universal_PSP.ptf` into `PSP/THEME/`.
5. Eject the storage safely and disconnect USB.
6. Open Settings → Theme Settings → Theme and select Rayman Raving Rabbids.
7. To revert, return to the same menu and select the original/default theme. If the console does not recognize the PTF, remove it from `PSP/THEME` and select the default theme.

Locations: PSP Go internal storage `ef0:/PSP/THEME/`; Memory Stick `ms0:/PSP/THEME/`. Menu wording may vary by firmware and language. The hardware has not been tested by the author of this package.
