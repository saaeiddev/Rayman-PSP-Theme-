# Compatibility report

Intended as a standard PTF theme for PSP-1000, PSP-2000, PSP-3000, PSP Go (N1000), and PSP Street (E1000), including firmware 6.60/6.61. Standard PTF does not require CXMB or flash modification. These are targets, not a verified compatibility guarantee: no hardware or emulator testing was available.

The fallback body/focus resources are included for PSP Go-specific entries, and no invented Go-specific PTF subtypes were written. The simulator preview is a visual mockup, not a firmware renderer. The hardware itself determines which menu entries appear; the PTF does not remove the UMD UI from a Go or alter XMB functionality.
